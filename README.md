# Project Title: Sprite Pet

This is a small RUST based game that uses the egui library. It's meant to mimic the old Tomagotchi games from the 90s. Right now it has one menu, which makes the Sprite Pet do one of three different emotes. Later features for the fully pet sim will be added later on. The sprites for this were made by me.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Once you have the repository downloaded you can run "cargo run" in the folder where you've stored it.

2. Another way to run it is by making a dedicated executable file, but I don't remember the commands for that.
3. If you decide to make it executable, you may need to copy sprite files into your target/assets folder in the project.

Instructions for using the software:

1. The left side button will open up your menu.
2. The center button is your selector or action button.
3. The right side button will close the menu.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* This program is run in RUST, which means you will need that for compiling.
* I also use the egui library, so you may need to download some packaging for that.
* I ran into problems when first compiling, that ChatGPT codex was able to trouble shoot and get working.
